# Publicación del perfil de GitHub — Condez

Este paquete contiene el README de perfil y el banner SVG. El contenido del `README.md` está en inglés para que el perfil mantenga una identidad profesional coherente.

## 1. Estructura que debes subir

En el repositorio público llamado exactamente `CondezJuan8`, deja esta estructura:

```text
CondezJuan8/
├── README.md
└── assets/
    ├── condez-hero.svg
    └── Condez_CV.pdf
```

- `README.md`: perfil completo.
- `assets/condez-hero.svg`: banner animado personalizado incluido en este paquete.
- `assets/Condez_CV.pdf`: **debes añadir tu hoja de vida real**. No se creó un PDF ficticio.

## 2. Añadir tu hoja de vida

1. Exporta tu CV final a PDF.
2. Nómbralo exactamente `Condez_CV.pdf`.
3. Súbelo dentro de `assets/`.
4. Comprueba que la URL `https://github.com/CondezJuan8/CondezJuan8/blob/main/assets/Condez_CV.pdf` abre el documento.
5. El botón `DOWNLOAD MY RESUME` del README apunta a `assets/Condez_CV.pdf`.

Si la rama predeterminada no es `main`, el enlace relativo del README seguirá funcionando desde GitHub.

## 3. Publicar en GitHub

1. Abre `https://github.com/CondezJuan8`.
2. Confirma que existe el repositorio público `CondezJuan8` (mismo nombre que el usuario).
3. Sube o reemplaza `README.md`.
4. Sube `assets/condez-hero.svg`.
5. Sube el PDF real del CV.
6. Abre tu perfil y revisa el resultado en escritorio y móvil.

GitHub muestra el Profile README cuando el repositorio público tiene el mismo nombre que el usuario y contiene un `README.md` en la raíz.

## 4. Mantenimiento

- Revisa las tarjetas de estadísticas si alguno de los servicios externos cambia de endpoint o deja de responder.
- Los contadores de GitHub son dinámicos y dependen de los límites y disponibilidad de cada proveedor.
- Mantén la sección de proyectos actualizada cuando cambien los README, lenguajes o estados.
- Añade proyectos a la sección de colaboración solo cuando los commits, pull requests, contribuyentes o documentación permitan verificar la participación de cada persona.
- El repositorio `CondezPancake` no se ha incluido como proyecto destacado porque la URL facilitada redirigió al repositorio de perfil `CondezJuan8` durante la revisión. Verifica el nombre o la URL correcta antes de añadirlo.
